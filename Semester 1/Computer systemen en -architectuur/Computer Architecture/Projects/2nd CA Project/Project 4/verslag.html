PROJECT 4: MEMORY

1. Build a 12-bit register using 12 D flip-flops

In deze vraag moeten we een 12-bits register maken met behulp van 12 D-flipflops in Logisim. Deze flipflops werken standaard op de rising edge. Daarom hebben we een inverter toegevoegd aan de clock om de flipflops op de falling edge te laten werken.

 

12-bit Register

2. Build a register file made of 8 of your own 12-bit registers.

Hier moesten we een register file maken bestaande uit 8 van onze 12-bits registers, waarmee we kunnen lezen en schrijven naar de 8 registers.
We hebben 7 inputs en 2 outputs:

·       Rs en rt bepalen welke registers worden gelezen; rs staat voor de index van de output S, en rt staat voor de index van de output T.

·       Rd is het register waarin de input Data wordt geschreven.

·       Als write = 1, mogen we in het register schrijven. Anders mogen we niet, zelfs als er een kloksignaal aanwezig is. Daarom gebruiken we de AND gates.

·       C is de clock, en als reset 1 is, wordt alles op nul gezet.

3. Build a counter using your own 12-bit carry lookahead adder and 12-bit register.

Hier moesten we een teller (counter) maken met twee inputs: clock en D (het maximale getal waartoe de teller kan tellen).
We hebben ons 12-bits register gebruikt om de waarde van de teller op te slaan, en de 12-bits CLA van het vorige verslag wordt gebruikt om de waarde van het register met 1 te verhogen.
Daarnaast hebben we een comparator gebruikt om het register te resetten wanneer de waarde groter dan of gelijk aan D is.

5. (Bonus) Build a 12-bit stack using the logisim RAM element.

Voor het 12-bits stack circuit hebben we drie multiplexers gebruikt:

1.      De eerste multiplexer kiest tussen het optellen of aftrekken van 1 bij het huidige adres.

2.      De tweede multiplexer kiest tussen de falling edge of rising edge van de klok voor het register dat de waarde van de counter bevat (hierbij is wat ingewikkelde logica toegepast).

3.      De derde multiplexer bepaalt welke waarde in de RAM wordt geschreven: de Data input voor een push-operatie of 0 als het een pop-operatie is.

De foutdetectie wordt uitgevoerd met twee AND-gates en één OR-gate. Een fout wordt gedetecteerd in de volgende gevallen:

·       Pop = 1 en de stack is leeg.

·       Push en Pop zijn tegelijkertijd gelijk aan 1.
