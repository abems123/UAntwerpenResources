PROJECT 6: FULL DATAPATH

Voor deze taak moesten we enkele instructies toevoegen aan onze eerdere datapad. De toegevoegde instructies waren: brnz, jr, j, en jal.

Hiervoor hebben we onze Program Counter verbonden met de datapad, zodat we direct naar de juiste instructie kunnen springen in plaats van automatisch naar de volgende instructie te gaan.

1.  Generating the Branch Value using a circuit

We beginnen met een nieuw circuit te maken die de branch value zal tellen. Die ziet er als volgt uit:

Het circuit heeft vijf inputs (branch absolute, branch relative, immediate, addr, rd, en opcode) en één output (branch value).

·       Branch absolute en branch relative worden bepaald door het controllercircuit.

·       Immediate, addr, rd, en opcode worden gegenereerd door het decoder circuit.

We gebruiken twee multiplexers om de branch value te genereren:

1.     De eerste multiplexer:

·       Heeft als selectorbit de output van een AND gate, die:

o   0 is wanneer het een branch absolute is. (jr, j en jal)

o   1 is wanneer het een branch relative is.    (brnz)

·       Output van de eerste multiplexer:

o   Als de selectorbit 0 is: de branch value wordt immediate + rd (voor de jr instructie).

o   Als de selectorbit 1 is: de branch value wordt gelijk aan de immediate (voor de brnz-instructie).

 

2.     De tweede multiplexer:

Heeft als selectorbit de output van een comparator, die controleert of de waarde van de opcode gelijk is aan 6.

·       Als de comparator 1 is (opcode = 6), wordt de addr-input geselecteerd. (voor j of jal)

·       Anders wordt de output van de eerste multiplexer geselecteerd. (voor jr of brnz)

2. Generating branch relative and branch absolute

Voor branch relative is dit alleen van toepassing bij de brnz instructie, omdat hierbij het huidige adres wordt opgeteld bij de immediate.

Om dit te bepalen, controleren we of:

·      De opcode gelijk is aan 5.

·      De LSB (least significant bit) van de instructie gelijk is aan 0.

Als beide voorwaarden waar zijn, wordt branch relative asserted.

Alle andere gevallen zijn branch absolute, omdat het volgende adres niet afhangt van het huidige adres, maar volledig wordt bepaald door de instructie zelf.

Om te bepalen of het branch absolute is, kijken we naar de volgende voorwaarden:

·       Als de opcode gelijk is aan 5 en de LSB (immbit) gelijk is aan 1, of

·       Als de opcode gelijk is aan 6.

In beide gevallen wordt branch absolute asserted, omdat het adres volledig door de instructie wordt bepaald, zonder afhankelijkheid van het huidige adres.

3. Generating rd en addr

Hier hebben we de outputs iets aangepast:

o   Rd is gelijk aan 7 in het geval van de jal-instructie, omdat we in dit geval r7 = pc + 1 moeten uitvoeren.

o   Rs is gelijk aan de bits [10-12] in het geval van addi, subi, jr, en brnz, omdat we in deze gevallen slechts 1 register nodig hebben.

o   Rt is gelijk aan de bits [10-12] in het geval van de sw-instructie. Voor de andere instructies is Rt gelijk aan de bits [4-6], omdat we voor de sw-instructie de waarde willen nemen die zal worden opgeslagen vanuit de tweede output van onze register file, namelijk T.

o   Addr is de bits [1-12] van de instructie

 

4. How do all elements work together?

Om de brnz-instructie te laten werken, moet de waarde van rd gelijk zijn aan 0. Wanneer het een brnz-instructie is, wordt de waarde van rd gelijk aan een output van de register file, namelijk S. Deze logica wordt geïmplementeerd in het decoder circuit.

·       Als rd = 0 en branch relative = 1, wordt de branch relative input van onze Program Counter (PC) geactiveerd, en de PC wordt bijgewerkt met PC + branch value + 1 om naar de juiste instructie te springen.

·       Als dit niet het geval is, wordt de PC gewoon naar de volgende instructie verhoogd (PC + 1).

Als branch absolute = 1, wordt de branch absolute input van de Program Counter asserted, en de PC springt naar de branch value.

De juiste branch value wordt gegenereerd door ons branch value generator circuit, dat ik eerder in sectie 1 heb uitgelegd.
