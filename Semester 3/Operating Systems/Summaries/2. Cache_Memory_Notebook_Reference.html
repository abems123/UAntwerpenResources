1
The Big Picture

Speed costs money and capacity costs speed. The hierarchy fakes having all three at once by betting on locality of reference.

going down: ↑ capacity · going up: ↑ cost & speed — SRAM (no refresh, fast, $$) → cache · DRAM (refresh, cheap, dense) → main memory

temporal locality → reuse same address soon
spatial locality → reuse nearby address soon
2
Anatomy of a Cache Access

CPU ↔ cache moves one word at a time on a fast on-chip bus. Cache ↔ memory moves one block at a time on a slower shared bus.

M blocks (K words each) ≫ C lines → C ≪ M
naive hit ratio H = C / M (real ratio is much higher — locality!)
block too small → less spatial payoff · too big → fewer lines, wasted fetch

5
Write Policies

A CPU write updates cache. Does memory find out now, or later? Matters because DMA reads memory directly, bypassing the cache.

6
Modern Designs

Real chips stack several caches, and sometimes split them by content.

inclusive: outer level duplicates inner (simple, wastes space)
exclusive: distinct data per level (more usable space, complex)
